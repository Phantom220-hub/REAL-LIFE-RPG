# REAL LIFE RPG — Roadmap

## Prototype 0.1
- [x] Godot project foundation
- [x] Offline local progression save
- [x] XP and levels
- [x] Workout entry (manual, for interface testing)
- [x] Basic enemy encounter button
- [ ] Automated project validation and Android export

## Prototype 0.2
- [ ] Character profile and attributes
- [ ] Proper combat rules, enemy health and rewards
- [ ] Inventory and equipment
- [ ] Daily quests with rest-friendly limits

## Prototype 0.3
- [ ] Camera permission and camera preview on Android
- [ ] Offline pose estimation integration
- [ ] Rep counting for one exercise, then careful device testing
- [ ] Clear confidence feedback and manual correction

## Later
- [ ] More enemies, bosses, locations and story
- [ ] Achievements and accessibility settings
- [ ] Performance and battery optimization

## Important
Camera-based exercise recognition is not implemented in 0.1. It requires a tested on-device model and native Android integration. The app must not upload camera footage. Exercise progress should never reward unsafe overtraining; rest and recovery are part of the game design.
